# ☀️ Solecito - Conversor CSV a Excel

Una aplicación web moderna, intuitiva y completamente accesible para convertir archivos CSV a formato Excel (.xlsx).

## ✨ Características

- **🎯 Interfaz Intuitiva**: Diseño moderno y fácil de usar
- **♿ Totalmente Accesible**:
  - Navegación completa con teclado
  - Etiquetas ARIA para lectores de pantalla
  - Soporte para modo de alto contraste
  - Respeta preferencias de reducción de movimiento
- **🎨 UI/UX Profesional**:
  - Diseño responsivo que funciona en todos los dispositivos
  - Animaciones suaves y transiciones fluidas
  - Feedback visual claro
- **📁 Drag & Drop**: Arrastra y suelta archivos CSV
- **👁️ Vista Previa**: Visualiza tus datos antes de convertir
- **⚙️ Personalizable**:
  - Selecciona diferentes delimitadores (coma, punto y coma, tabulador, etc.)
  - Indica si tu archivo tiene encabezados
- **🔒 Privacidad Total**: Todo se procesa localmente en tu navegador
- **⚡ Rápido y Eficiente**: Conversión instantánea

## 🚀 Uso

1. Abre `index.html` en tu navegador
2. Arrastra un archivo CSV o haz click para seleccionarlo
3. Revisa la vista previa de tus datos
4. Ajusta las opciones si es necesario (delimitador, encabezados)
5. Haz click en "Convertir a Excel"
6. Tu archivo .xlsx se descargará automáticamente

## 📦 Instalación para Desarrollo

```bash
# Clonar el repositorio
git clone [url-del-repositorio]

# Navegar al directorio
cd alonso

# Instalar dependencias
npm install

# Iniciar servidor local
npm start
```

La aplicación estará disponible en `http://localhost:8080`

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Estilos modernos con variables CSS y animaciones
- **JavaScript (ES6+)**: Lógica de la aplicación
- **SheetJS (xlsx)**: Librería para generar archivos Excel

## ♿ Características de Accesibilidad

- **Skip Link**: Permite saltar al contenido principal
- **Navegación con Teclado**: Todos los elementos son accesibles por teclado
- **ARIA Labels**: Etiquetas descriptivas para tecnologías asistivas
- **Live Regions**: Anuncios dinámicos para lectores de pantalla
- **Focus Visible**: Indicadores claros de foco
- **Alto Contraste**: Soporte para modo de alto contraste
- **Reducción de Movimiento**: Respeta preferencias de animación

Todos los archivos se procesan **100% localmente** en tu navegador. No se envían datos a ningún servidor externo. Tus archivos permanecen completamente privados y seguros.
